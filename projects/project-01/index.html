Dashboard interactivo de ventas de videojuegos en Power BI

Análisis de videojuegos

Explora las ventas de videojuegos con un dashboard interactivo en Power BI. Compara regiones, años, plataformas y géneros mediante sus filtros. Este proyecto muestra las ventas de videojuegos por región, año, plataforma y género. Utiliza los filtros de año, región, género, editorial y plataforma para comparar segmentos y explorar su evolución.

Activa JavaScript para ver el dashboard integrado o utiliza el enlace para abrirlo en una nueva pestaña.
