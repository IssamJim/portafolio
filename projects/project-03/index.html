Mapa interactivo: parques, volcanes y población

Explora parques de Hermosillo, volcanes de Estados Unidos y una capa mundial de población mediante un mapa interactivo creado con Python y Folium.

Explora el mapa

La capa de población utiliza POP2005 (2005), no datos actuales. Activa o desactiva las capas desde el control del mapa. El mapa base requiere conexión a Internet.

Cómo leer el mapa

Los colores se reutilizan entre capas y tienen un significado diferente en cada una. No expresan una valoración de calidad.

Controles y símbolos

  • Capas: activa o desactiva parques, volcanes y población. Desactivar población permite ver con mayor claridad el mapa base y los puntos.
  • + / −: acerca o aleja la vista; arrastra el mapa para desplazarte.
  • Los marcadores tienen el mismo radio: su tamaño no representa superficie ni altura.
  • Selecciona un círculo para consultar sus datos. Con teclado, usa Tab para enfocar un marcador y Enter o Espacio para abrirlo; Escape cierra la información.

Sobre el proyecto

Objetivo

Reunir datos de parques, volcanes y población en un mapa por capas para consultar su ubicación y atributos, y comparar las categorías definidas en el proyecto.

Tecnologías y herramientas

  • Python y pandas: lectura de los datos de parques en Excel y de volcanes en CSV.
  • Folium: creación de las capas, los marcadores y el archivo HTML del mapa.
  • GeoJSON: geometrías y atributos de la capa mundial de población.
  • Leaflet: navegación, controles de capas y ventanas de información en el navegador.
  • OpenStreetMap: mapa base y atribución de sus colaboradores.

La clasificación, en código

Función original de map1.py. Se utiliza tanto para la superficie de los parques como para la altura de los volcanes, aunque son magnitudes y unidades distintas.

def color_producer(superficie):
    if superficie < 960:
        return 'green'
    elif 960 <= superficie < 3350:
        return 'orange'
    else:
        return 'red'

Son recuentos de registros, no una garantía de lugares únicos ni de cobertura completa.

El proyecto muestra cómo combinar datos tabulares y geográficos en una visualización por capas. La interpretación exige identificar la unidad de cada variable, explicar los umbrales y conservar la fecha del conjunto de datos.

Se mantienen las coordenadas, atributos y categorías originales. No se han actualizado ni verificado de nuevo su exactitud geográfica o su vigencia.
